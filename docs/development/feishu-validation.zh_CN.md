# 飞书可靠性与验证

独立检出为 `apps/feishu`，分支 `feature/feishu-reliability`，基于上游
`c101494ff9031e29cf147923f434edea5d6c71cb`。范围是 /26 独立应用可靠性、
镜像体积、PassportSim 集成验证及后续已授权的实机验收，不扩展 ZION Runtime 实验。

## 配网取消、提示刷新与应用入口兼容（2026-11-04）

现场确认提交配网后已进入飞书应用准备阶段。相同接口返回的设备授权码长 514 字节，
旧上限 256 会拒绝响应；同页状态变化又未重绘，导致一直显示连接 Wi-Fi。
本版扩展为有界 1,024 字节，并按实际转义长度分配轮询表单，不增加固定大栈数组。

| 验证 | 结果 |
| --- | --- |
| 主机协议回归 | 514 字节、1,023 字节边界、超限拒绝、最坏转义与原有异常用例通过 |
| 真机取消与恢复专项 | Wi-Fi 取消 154 ms，随后联网成功；HTTPS 取消后重新注册成功，取得 514 字节授权码并正常轮询 |
| 正式版启动 | 约 5.17 秒进入应用选择阶段，40 秒无故障标记，身份区读回一致；APP 3,222,800 字节 |
| 待人工验收 | 实体确定键长按返回免密码配网，再次提交后重新进入应用二维码；选／建应用和用户授权 |

专项使用 16 KiB 测试任务且无完整 UI，不能把其时延或堆作为完整产品指标。
正式版本仍为 2 bpp 字体、免密码热点，绑定及已提交的 Wi-Fi 保留。
证据：`build/onboarding-cancel-product-verified/report.json`。存储压力问题仍未关闭。

回归源为 `tools/storage_probe/vfs_contract.c`。完整产品构建及最终恢复证据见本轮报告。
