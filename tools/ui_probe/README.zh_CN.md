# 设备界面与网络冒烟测试

[English](README.md)

当前已安装的普通变体显式选择`-DFEISHU_ASR_BACKEND=xiaozhi`。
在实体操作验收前，源码默认仍保留飞书识别后端；选择后端本身不等于验证通过。

诊断构建需在环境中同时设置`FEISHU_UI_AUTOTEST=1`与
`FEISHU_NETWORK_UI_AUTOTEST=1`，再选择小智后端构建。普通APP保持两个变量未设置。
构建与刷机是两个步骤；保留分区布局、身份、配套字体、绑定及共享数据池。

LVGL线程测试配对刷新与冷却、草稿颜色、密码键盘布局、默认添加焦点、单网络菜单和
焦点重绘，以及实际扫描后进入密码页。工作线程测试取消、保留当前活动项的密码编辑、
错误保存密码回退、主动断开与重连、错误候选网络、扫描及真实会话读取。
当已记忆网络恰好只有一个时，会临时忘记该网络，再从RAM快照恢复并重新连接。
这项测试中途不要断电。

成功必须同时出现`PAIR_UI_SMOKE_DONE pass=1`与
`NETWORK_UI_SMOKE_DONE pass=1`，随后恢复普通APP并验证启动。失败不能计作通过。
测试不发送消息、不解除配对、不播放音频，也不输出SSID、密码或令牌。
它们不能替代实体按键、麦克风、手机配网及真实断电验收。普通固件不启用这些测试。
