# 设备端只读MCP原型

[English](README.md)

显式启用 `FEISHU_MCP_DIAGNOSTIC=1` 并选择小智后端，才会编译诊断及主机协议测试；
普通语音识别产品不会因此开启MCP。资源对照使用关闭独立堆跟踪的普通配置。

设备连接自身已配置服务，完成MCP协商，仅公开一个聚合状态只读工具。在本地回放状态
调用后，保持WSS连接并读取一条真实飞书消息，再检查ping/pong。单消息分页是明确的
内存边界，不证明八消息工作区可共存，也不证明云端语义工具调用。工具不提供音频、
消息发送、凭据读取或设置修改。

协议限制：输入4,096字节、深度10、结构/标量/键事件128个、输出1,024字节，限制ASCII
请求ID和会话长度。先检查UTF-8、结构、重复键、参数与会话，再构建小型cJSON树；打开
飞书HTTPS前释放协议工作区。错误与分配失败后下一请求仍可处理。模块不访问LVGL。

有界测试结束后恢复已验证普通APP。保留分区表、身份、配套字库、数据池及草稿；
报告中不记录原始连接配置和令牌。
