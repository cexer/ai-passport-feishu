# 有界内存诊断

[English](README.md)

诊断构建需显式启用 `FEISHU_MEMORY_DIAGNOSTIC=1`。完成正常身份鉴权后，分别执行
直接使用编解码器、短生命周期麦克风任务、真实消息读取/缓存发布、稳定麦克风并行
消息读取，各二十次。音频不上传、不播放，不发送消息；沿用身份、绑定、草稿和数据池。

每次记录空闲/最大块/最低堆、任务数和堆完整性。可选启用独立堆跟踪及四层调用栈，
在两个音频阶段记录尚未释放的分配。跟踪额外开销与普通版运行测量必须分开解释。
完整性失败或稳定空闲堆低于60,000字节时停止。程序计数器必须用匹配ELF解码。

必须准备已验证普通版用于恢复。只在已确认偏移写入APP，诊断前后检查分区表、身份
窗口和配套字库，并确认普通版带绑定正常启动。
